# Contributing

Small, focused pull requests are welcome. For a larger change, open an issue first so the approach can be discussed.

Build with `./Scripts/build_app.sh` on an Apple-silicon Mac with Xcode installed. Check importing a song, playback, seeking, lyric import, removing a song, and reopening the app. For animation changes, check playback and scrolling together, including Reduce Motion.

Describe the behavior changed and how you tested it. Include a screenshot for visual changes. Do not commit music, lyric files, downloaded album covers, credentials, build output, or personal library data.

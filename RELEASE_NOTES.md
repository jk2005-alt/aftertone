Aftertone’s first public macOS release.

A native player for your own MP3 library, with synchronized lyrics, rotating album artwork, and an animated Earth background.

### Download and install

1. Download **Aftertone-macOS-arm64.zip** below.
2. Extract it and move **Aftertone.app** to **Applications**.
3. Launch Aftertone and choose **Add** to import your own music.

**Requires macOS 14 or later and an Apple-silicon Mac.** Intel and Windows builds are not included.

### Controls

**Click the rotating album disc to pause or resume playback.** Use the progress bar to seek and the bottom-right slider to adjust volume. Double-click the lyrics area for full screen; Escape returns to the library.

The top-left lyrics button lets you import an LRC file or paste plain lyrics. Timed lyrics require timestamps that match the recording.

### Release notes

- Create and remove categories; move songs between them without duplicates.
- Native local audio playback and alphabetically sorted library.
- Timed LRC and plain-text lyric import and editing.
- Library removal that preserves your original files.
- Animated Earth backdrop and album-disc playback control.
- No bundled songs, lyric files, or album-art library.

This release is ad-hoc signed, not Apple-notarized. macOS may block the first launch. If you trust the download, follow [Apple’s Open Anyway instructions](https://support.apple.com/en-us/102445). The source is available for building locally.
